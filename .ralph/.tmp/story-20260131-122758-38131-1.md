### US-001: TypeScript CLI の初期セットアップ
Status: in_progress
Depends on: None

Description:
As a developer, I want a TypeScript-based CLI project scaffold so I can run the simulator with npm scripts.

Acceptance Criteria:
- [ ] package.json に npm scripts を追加（start/test/build など）
- [ ] TypeScript 設定ファイル（tsconfig）を追加
- [ ] Example: npm run start で 'Scenario A/B/C' の実行が開始される
- [ ] Negative case: npm run start を実行しても ts-node/tsx が未導入ならエラーになるため、必要な依存関係をインストールする
- [ ] 依存追加は明示的に npm install tsx typescript @types/node などを記載
