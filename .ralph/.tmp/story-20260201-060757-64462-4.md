### US-006: テストでコアロジックとシナリオを検証
Status: in_progress
Depends on: US-002, US-004

Description:
As a developer, I want unit tests and scenario tests so correctness is enforced.

Acceptance Criteria:
- [ ] ダメージ式、POISON/STUN、クールダウン等のユニットテストを用意
- [ ] シナリオA/B/Cの期待挙動をテストで検証（ログ or 状態）
- [ ] Example: シナリオAのターン1でGuardianがGuard Stance、BladeがBerserkになる
- [ ] Negative case: シナリオAでヒール条件未満の場合はヒールが発動しないことを確認
