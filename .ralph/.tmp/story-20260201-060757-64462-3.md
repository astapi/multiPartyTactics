### US-005: 最低限ログと簡易レポート出力を実装
Status: in_progress
Depends on: US-004

Description:
As a developer, I want required logs and a simple report so debugging and summaries are easy.

Acceptance Criteria:
- [ ] 各ターンで: ターン番号/行動者/ルール評価結果/実行行動/ダメージ・回復/状態異常付与・解除 を出力
- [ ] 簡易レポートを JSON で出力（例: ./reports/summary.json）
- [ ] Example: summary.json に各シナリオの勝敗・ターン数が含まれる
- [ ] Negative case: reports ディレクトリが無い場合は自動作成する
