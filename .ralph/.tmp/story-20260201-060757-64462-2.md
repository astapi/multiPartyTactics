### US-004: シナリオA/B/Cを固定定義しCLI実行で連続実行
Status: in_progress
Depends on: US-003

Description:
As a developer, I want fixed scenarios A/B/C to run in CLI so behavior can be verified deterministically.

Acceptance Criteria:
- [ ] npm run start 実行でシナリオA→B→Cの順に実行される
- [ ] 乱数がある場合は固定seedで再現可能にする
- [ ] Example: シナリオBでPOISON付与後にCleanseが割り込むログが出る
- [ ] Negative case: シナリオCで毒が無いとCleanseは不成立となり次ルールへ進む
