### US-002: 戦闘コア（ターン/行動/ダメージ/状態）を実装
Status: in_progress
Depends on: US-001

Description:
As a developer, I want core battle rules implemented so that units can act, deal damage, and apply statuses per spec.

Acceptance Criteria:
- [ ] ターン順は spd 降順で決定し、同速は固定ルール（例: 先頭優先）で処理
- [ ] 物理ダメージ式 max(1, power + atk - def) が適用される
- [ ] POISON と STUN の付与/解除/経過が処理される
- [ ] Example: POISON(3turn) で毎ターン固定ダメージが発生する
- [ ] Negative case: 既にSTUN中のユニットにSTUNが再付与されても、上書きルールに従って矛盾しない
