# モンスター画像リスト

## ファイル命名規則

- 画像ファイル名は `{enemy_id}.png` で統一する（`src/data/enemies.json` の `id` に一致）
- 配置先: `src/assets/images/enemies/`
- ボス画像: `src/assets/images/enemies/boss/`
- 1モンスター = 1画像ファイル（複数モンスターで画像を共有しない）
