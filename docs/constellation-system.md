# 星座システム仕様（実装ベース）

最終更新: 2026-02-25

## 概要

- キャラクターごとに `星座` を1つ付与するシステム
- 星座は `キャラクター生成時にランダム抽選` で決定
- 星座の効果は `レベルアップ時の成長量` にのみ反映
- `初期ステータス補正` には影響しない
- `戦闘中の直接補正`（命中/ダメージ倍率など）には影響しない

## 実装済み範囲

- 24種の星座を実装
  - 12星座
  - 追加12種（聖闘士星矢寄りのモチーフ）
- 星座ごとの成長ボーナス定義
  - 対象ステータス: `maxHp / atk / def / spd / maxMp / mpRegen`
- キャラクターDB保存
  - `characters.constellation_id`
- 既存DB向けマイグレーション
- キャラクター詳細画面での星座表示

## 星座ボーナス仕様

### ボーナスの意味

- 各星座は「レベルごとの成長量に加算される係数」を持つ
- 実際の加算は以下の式で行う

```ts
最終成長係数 = クラス成長係数 + 星座成長ボーナス
最終ステータス = Lv1基礎値 + floor((level - 1) * 最終成長係数)
```

### 重要仕様（初期値補正にならない理由）

- 計算に `level - 1` を使うため、`Lv1` 時点では星座ボーナスは0
- そのため、仕様どおり「初期ステータス補正ではない」

## 抽選仕様

- 付与タイミング: キャラクター作成時
- 抽選方法: `Math.random()` ベースで `CONSTELLATION_MASTER` から等確率抽選
- 現状の抽選対象: 24種すべて

### 実装上の注意

- 既存キャラはマイグレーションで `ARIES`（牡羊座）を既定値として保存される
- 既存キャラをランダム再付与したい場合は、別途ワンショット処理が必要

## データ構造 / 保存仕様

### CharacterRecord

- `constellationId: ConstellationId` を追加

### DB（charactersテーブル）

- 追加カラム: `constellation_id TEXT NOT NULL DEFAULT 'ARIES'`
